Frequently Asked Questions

Simple answers for new and active users.

What is TraidiumX?

TraidiumX is a frontend prototype for a crypto derivatives platform interface with markets, futures, options and crypto wallet pages.

Is this a real exchange?

No. This is frontend-only right now. Real exchange, FIU, compliance, legal and audit claims should be added only after company verification.

Is the backend connected?

Yes. The main trading flow uses Flask APIs, MongoDB collections, authentication, KYC, wallet ledger, markets, futures and options services.

Is the design responsive?

Yes. The layout is built with Tailwind CSS and supports mobile, tablet, laptop and desktop screens.
